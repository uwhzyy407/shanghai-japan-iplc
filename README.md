## 一、沪日 IPLC 到底是哪类专线，适合什么人用

「沪日」指的是上海到日本，「IPLC」全称 International Private Leased Circuit，国际私有专线。和普通公网出口不同，IPLC 是从国内入口直接拉到海外节点运营商的内网，跳过公网拥堵，所以单程延时通常能压到 30ms 以内。

对照来看：

- 普通公网访问日本（例如走普通的 CN2 GIA、家宽出国）：单程一般在 80–150ms，夜间抖动大，偶尔丢包。
- IPLC/IEPL 专线：单程稳定在 25–35ms，方向可控，且具备双端独立 IP 的能力。

那这条沪日 IPLC 适合谁？常见的实际用法包括：

- 跨境电商：日区 Amazon、乐天、Yahoo 店铺多账号运营，需要稳定的日本原生 IP。
- 内容/自媒体：日区 YouTube Premium、Netflix、Disney+、Dazn 等流媒体订阅与原创分区内容。
- AI 工具：ChatGPT、Claude、Gemini 的日本区账号，配合流量较大的批量调用。
- 远程办公：SSH 加速、远程桌面、跨境会议、稳定传文件等。
- 游戏/服务：日服游戏、语音服务器、Teamspeak 等对延迟敏感的场景。

需要先打底说明的是，按中国大陆法规，所有市售 IPLC/IEPL 专线都需要国内手机号实名认证，MKCloud 的沪日 IPLC 也包含省级白名单（仅允许登记省份 IP 连入）。买之前要确认这一点自己能够接受。

## 二、MKCloud 沪日专线的三种入口，选错就会后悔

MKCloud 的沪日专线在「产品大类」层面只有一条：上海-日本 IPLC 专线。但在「入口」这一层被拆成了三种截然不同的接入方式，套餐参数和价格完全不同。这是它和很多「沪日」商家不一样的地方，也是搞清楚价格之前必须先看的一项。

### 1. 上海电信入口（直接电信出口）

入口为上海电信骨干，出口为日本 BGP，自己机房直接对接。无前置机依赖，但是只能允许登记的某一个省份的 IP 连接。适合「我能保证本地就是固定省份出口」的个人或工作室。

官网路径：`/index.php/store/sh-jp-sh`

### 2. 上海 BGP 入口（三网 BGP 入口）

入口侧挂在腾讯云、阿里云上海 BGP 之上，相当于「电信 + 联通 + 移动」三网都通。担心跨网问题的用户可以选购这一档。价格通常比电信入口略高。

### 3. 上云互联优化入口（IXP）

入口是阿里云/腾讯云国内 BGP 网络，出口为日本 BGP，并经 IX 互联优化。优势是无省份白名单（只要云厂 BGP 网络环境都能连），且带宽上限更高。这个入口适合搭配云厂前置机使用，但前提是：你得有自己的阿里云/腾讯云 BGP 内网主机。

需要看清楚的是：MKCloud 沪日专线有两种计费方式——「流量计费（共享带宽）」和「带宽计费（独享带宽）」。前者按月给配额，超量会限速或停机；后者是真正不限流量、独占带宽。下面的两张套餐表分别覆盖二者。

## 七、合规、付款与限制：买之前必须知道的几件事

这部分有点像「菜单警告」，但沪日 IPLC 是受合规强约束的产品，不解释清楚容易踩坑。

### 1. 实名认证

MKCloud 沪日 IPLC/IEPL 产品均要求国内手机号实名（依据《网络安全法》第二十四条）。企业用户需提供营业执照与负责人身份信息，个人用户提供身份证 + 手机号即可。

### 2. 支付方式

目前官网明确仅支持支付宝，企业用户可走对公。没有 PayPal、没有信用卡通道，这一点对海外华人来说是个明显的取舍点。

### 3. 省级白名单

上海电信入口、上海 BGP 入口的沪日专线都强制绑定单一省份。开通后只能从你登记的省份 IP 连入，后续可在工单里更换省份。IXP 入口则需要云厂 BGP 内网主机，没有此限制。

### 4. 退款政策

仅支持质量问题退款，开通后不支持更换其他地域。质量问题需自行提供具体延迟、速度数据作为佐证。这一点和其它商家「7 天无理由」区别明显。

### 5. 用途限制

明文禁止用作机场、回国等违法违规用途。这种合规边界让产品更偏向「企业级 / 自用型」，而非「通用代理服务」。

### 6. 优惠码更新频繁

MKCloud 历次节日活动都会发优惠码，例如节庆期间流量计费产品循环 8.8 折（MK-8.8）、独享带宽产品首月 7.8 折（MK-7.8）以及新客 MK-NEW。**这些优惠码仅在活动期内有效**，下单前建议先看 [官网公告页](https://bit.ly/MKCLoud) 当前是否有可用码。

## 九、FAQ：常被问到的问题

**沪日 IPLC 一定要做实名认证吗？** 是。MKCloud 所有 IPLC/IEPL 都要求国内手机号实名，个人要身份证号，企业要营业执照。

**可以用美国信用卡 / PayPal 吗？** 不可以，目前官方仅支持支付宝，企业用户需要走对公。

**是原生日本 IP 吗？** 是。出口走日本 BGP，测试结果显示 Netflix、Disney+、ChatGPT 等都能识别为日区。

**会不会被滥用审查？** 该产品对机场、回流等场景明令禁止，只针对个人 / 企业自用方向开放。

**独享带宽可以选多高？** 目前 MKCloud 沪日线独享带宽最高可达 300M，再往上是大客户定制，需要联系客服。

**退款政策严吗？** 比较严：要质量问题退款，必须自己提供延迟、速度的具体数据；开通后不能更换地域。这一点买之前要算清楚自己需求量。

**买完发现不够用，能加流量吗？** 可以，自助购买流量重置包或升级套餐，也可以提交工单补差价。

**几条日本方向专线在 MKCloud 这边的 IPLC 和 IEPL 是什么关系？** 沪日方向官方资料显示，走的是 IPLC（国际私有专线），而广港是 IEPL（国际以太网专线）。两者都是高质量跨境方案，区别在于承载协议，业务效果接近，但前者天然更偏 IP 协议，后者多见于企业以太网场景。
